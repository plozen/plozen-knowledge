# API Smoke Test - 2026-05-29

## Environment

- API: `uvicorn plozen_knowledge_api.main:app --host 0.0.0.0 --port 8100`
- DB host: `<db-host>:<db-port>`
- Embedding provider: `fake`
- API guard: `KNOWLEDGE_API_KEY=<local-smoke-key>`
- Target DB: `plozen_knowledge`

## Commands

Health check:

```bash
curl http://127.0.0.1:8100/health
```

Document ingest:

```bash
curl -X POST http://127.0.0.1:8100/documents/ingest \
  -H "Content-Type: application/json" \
  -H "X-Knowledge-Api-Key: ${KNOWLEDGE_API_KEY}" \
  -d '{
    "source_type": "manual_note",
    "source_uri": "manual://rag-api-mvp-smoke-2026-05-29",
    "title": "RAG API MVP Smoke",
    "content": "# PLOZEN Knowledge API\n\nPLOZEN Knowledge는 문서를 청킹하고 embedding으로 pgvector 검색을 수행합니다.\n\n## Console Boundary\n\nPLOZEN Console은 Knowledge Center UI를 담당하고, Knowledge API는 ingest, chunking, embedding, search를 담당합니다.",
    "metadata": {"project": "PLOZEN Knowledge", "smoke": "api-mvp"}
  }'
```

Search:

```bash
curl -X POST http://127.0.0.1:8100/search \
  -H "Content-Type: application/json" \
  -H "X-Knowledge-Api-Key: ${KNOWLEDGE_API_KEY}" \
  -d '{"query":"PLOZEN Knowledge Console chunking search", "top_k": 3, "filters": {"project": "PLOZEN Knowledge"}}'
```

Idempotency check:

```bash
curl -X POST http://127.0.0.1:8100/documents/ingest \
  -H "Content-Type: application/json" \
  -H "X-Knowledge-Api-Key: ${KNOWLEDGE_API_KEY}" \
  -d '{...same payload...}'
```

Auth guard check:

```bash
curl -i http://127.0.0.1:8100/documents
curl -i -H "X-Knowledge-Api-Key: ${KNOWLEDGE_API_KEY}" http://127.0.0.1:8100/documents
```
